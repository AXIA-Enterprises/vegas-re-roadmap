# Las Vegas real-estate domain portfolio: monetization roadmap

An internal monetization roadmap for a portfolio of Las Vegas real-estate `.com` domains. It covers:

- keyword opportunity and per-domain roles (build, redirect or park)
- monetization models and their licensing risk
- Nevada and federal compliance notes
- SEO, content and citation plans
- a phased roadmap, plus risks and mitigations

## Structure

Static HTML/CSS with no build step and no JavaScript. It is served from the repository root (it works on GitHub Pages).

| File | Contents |
| --- | --- |
| `index.html` | Executive summary and top recommendations |
| `domains.html` | Keyword table and per-domain plan |
| `monetization.html` | Revenue models, benchmarks, IDX path |
| `legal.html` | NRS 645, NRED, RESPA Section 8 |
| `seo.html` | Build vs. redirect, content plan, citations and backlinks |
| `roadmap.html` | Phases, order of work, risks |
| `sources.html` | All cited sources |
| `styles.css` | Shared styles |

Every page carries `noindex, nofollow`, and `robots.txt` disallows all crawling. The legal material is a planning summary, not legal advice.
